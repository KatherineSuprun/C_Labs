Під час виконання лабораторної роботи № 3, частини 1, було розроблено програму мовою C для дослідження функції відповідно до варіанта 7.
 Реалізовано два способи введення початкових даних: через кількість точок та через крок зміни аргументу. Створено таблиці значень
 функції та її першої похідної, а також реалізовано пошук можливих проміжків ізоляції коренів рівняння.
 Отримані результати дають змогу дослідити поведінку функції та підготувати дані для другої частини лабораторної роботи.
